## Twilio API Integration

### Search Available Numbers

```csharp
// Configuration approach (NO hardcoding)
public class TwilioSettings
{
    public string AccountSid { get; set; }
    public string AuthToken { get; set; }
    public string DefaultCountryCode { get; set; } = "US";
    public Dictionary<string, string> CountryConfigs { get; set; }
}

// Service implementation
public async Task<List<AvailablePhoneNumber>> SearchAvailableNumbers(
    string countryCode,
    string areaCode = null,
    bool voiceEnabled = true,
    bool smsEnabled = true)
{
    var options = new AvailablePhoneNumberLocalOptions
    {
        PathCountryCode = countryCode,
        VoiceEnabled = voiceEnabled,
        SmsEnabled = smsEnabled,
        AreaCode = areaCode
    };

    var numbers = await AvailablePhoneNumberResource.ReadAsync(
        options: options,
        limit: 20
    );

    return numbers.Select(n => new AvailablePhoneNumber
    {
        PhoneNumber = n.PhoneNumber.ToString(),
        FriendlyName = n.FriendlyName,
        Capabilities = new
        {
            Voice = n.Capabilities.Voice,
            SMS = n.Capabilities.Sms,
            MMS = n.Capabilities.Mms
        }
    }).ToList();
}
```

### Provision Number

```csharp
public async Task<PhoneNumber> ProvisionPhoneNumber(
    string userId,
    string phoneNumber,
    string countryCode)
{
    // Purchase from Twilio
    var twilioNumber = await IncomingPhoneNumberResource.CreateAsync(
        phoneNumber: new PhoneNumber(phoneNumber),
        voiceUrl: new Uri(_settings.VoiceWebhookUrl),
        smsUrl: new Uri(_settings.SmsWebhookUrl),
        statusCallback: new Uri(_settings.StatusCallbackUrl)
    );

    // Save to database
    var number = new PhoneNumber
    {
        UserId = userId,
        Number = phoneNumber,
        CountryCode = countryCode,
        TwilioSid = twilioNumber.Sid,
        TwilioAccountSid = twilioNumber.AccountSid,
        VoiceEnabled = true,
        SmsEnabled = true,
        IsPrimary = !await HasExistingNumbers(userId)
    };

    await _repository.AddAsync(number);
    return number;
}
```

### Enable WhatsApp

```csharp
public async Task<bool> EnableWhatsAppForNumber(string phoneNumberSid)
{
    // Configure WhatsApp messaging service
    var messagingService = await MessagingServiceResource.CreateAsync(
        friendlyName: "WhatsApp Service"
    );

    // Add phone number to messaging service
    await PhoneNumberResource.CreateAsync(
        pathServiceSid: messagingService.Sid,
        phoneNumberSid: phoneNumberSid
    );

    // Request WhatsApp enablement (requires Meta approval)
    return true;
}
```

## Cost Optimization Strategy

### Number Pooling for Trial Users
- Share phone numbers among trial users
- Separate once they convert to paid
- Reduces trial costs by 90%

### Geographic Optimization
- Assign local numbers to reduce call costs
- Toll-free for enterprise customers
- Mobile numbers for SMS-heavy users

### WhatsApp First Strategy
- Encourage WhatsApp for low-cost messaging
- Service messages (user-initiated) are FREE
- Can reduce messaging costs by 60-80%

## Configuration Best Practices

### Environment Variables (NO HARDCODING)

```bash
# appsettings.Production.json
{
  "Twilio": {
    "AccountSid": "${TWILIO_ACCOUNT_SID}",
    "AuthToken": "${TWILIO_AUTH_TOKEN}",
    "DefaultCountryCode": "US",
    "VoiceWebhookUrl": "https://api.speakhalo.com/api/v1/webhooks/twilio/voice",
    "SmsWebhookUrl": "https://api.speakhalo.com/api/v1/webhooks/twilio/sms",
    "StatusCallbackUrl": "https://api.speakhalo.com/api/v1/webhooks/twilio/status",
```
